## Память и процессор

Процесс, в котором загружены `openpyxl`, `httpx`, `trafilatura`, `ddgs` и `deep_translator`, занял **51 417 088 байт** рабочей памяти. Пик совпал с этим значением. На импорт ушло **0,73 с** процессорного времени, затем процесс простаивал.

Последний поиск (`--limit 3`) шёл **67,8 с** и завершился. Постоянного процесса, порта и опроса нет. Цикл в `scripts/monitor.py` только листает страницы поиска, пока скрипт запущен.

## Где что работает

На сервере: `python3 scripts/monitor.py`, сборка HTML и Excel, файлы в `data/` и `output/`.

Не на сервере:

- Google Таблица и `scripts/google_sheets_script.gs`. Таймер в коде: понедельник, около 8:00, функция `buildSheet`. Он ставится вручную через `installWeeklyTrigger` и крутится у Google.
- GitHub хранит репозиторий. Таблица читает JSON оттуда, не с диска сервера.
- Поиск идёт в DuckDuckGo, страницы скачиваются по HTTP, перевод — через MyMemory или Google Translate. Ключей в проекте нет.

Файла crontab в репозитории нет. `scripts/run_local.ps1` — запуск для Windows, без расписания. На Ubuntu строку cron нужно добавить самим, например раз в неделю. После выполнения скрипт не остаётся в памяти.
